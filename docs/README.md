# Docs Index

This folder contains product and reference material. Agent operating rules live in root `AGENTS.md`.

## Gates

- `product/DEVELOPMENT_PLAN.md` — read when changing the core vocabulary model, merge flow, sync order, Telegram commands, scheduling, logging, or MVP scope.
- `product/POCKETBOOK_GOALS.md` — read when working on PocketBook Cloud auth, fetching, note parsing, manual exported notes fallback, sanitized fixtures, or PocketBook source anchors.
- `product/SPREADSHEET_GOALS.md` — read when working on Google Sheets credentials, sheet/range config, row parsing, metadata writeback, or spreadsheet source anchors.

## Rules

- Keep long product requirements here, not in `AGENTS.md`.
- Keep `AGENTS.md` concise and operational.
- Add a new entry to this index whenever adding a new doc.
- Update `RHYTHM.md` when a doc move or product decision changes how future work should be done.
